Krish Kanda — Portfolio
=======================

Files:
  index.html   the page (open this in a browser)
  styles.css   all styling
  script.js    all animations & interactions

To view locally:
  Just open index.html in any browser — double-click it.

To deploy free on GitHub Pages:
  1. Create a new GitHub repo (e.g. "portfolio").
  2. Upload all three files (index.html, styles.css, script.js) to the repo root.
  3. Repo Settings > Pages > Source: "Deploy from a branch" > main / root.
  4. Your site goes live at https://<username>.github.io/portfolio/

Note: index.html loads two web fonts from Google Fonts, so keep an
internet connection the first time it renders.

BEFORE PUBLISHING — one thing to edit:
  In index.html, find the UT Austin status pill that reads
  "ADMITTED · EDIT ME" and change it to match your real admission
  status (or remove the <span class="status"> line).
